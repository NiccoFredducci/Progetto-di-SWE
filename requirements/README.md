# Documenti sorgente locali

Copia direttamente qui i documenti originali di requisiti e corso: PDF, immagini e file di testo. Non creare sottocartelle e non modificare gli originali.

I file aggiunti a questa cartella sono esclusi da Git tramite `.gitignore`, quindi restano sul tuo computer e non vengono pubblicati con il repository. Questo README e il file `.gitkeep` sono gli unici elementi tracciabili e spiegano/garantiscono la presenza della cartella.

Dopo aver aggiunto i documenti, chiedi all'agente di analizzarli e aggiornare `../REQUIREMENTS.md` con riferimenti a documento e pagina o sezione. Rivedi tu il risultato.
